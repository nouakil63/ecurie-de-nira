# Écurie de Nira

Plugin WordPress **Nira Booking** : système de réservation pour les gîtes des Écuries de Nira (calendrier façon Airbnb, paiement Stripe, synchronisation iCal, tableau de bord admin).

## Contenu

- `nira-booking/` — le plugin WordPress complet (v2.0.2). Voir `nira-booking/readme.txt` pour la description détaillée et les instructions d'installation.

## Installation rapide

1. Zipper le dossier `nira-booking/`.
2. Dans WordPress : Extensions → Ajouter → Téléverser une extension.
3. Activer le plugin, puis configurer les clés Stripe dans les réglages (jamais dans le code).
